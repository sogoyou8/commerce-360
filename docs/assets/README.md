# Commerce 360 — captures publiques

Ces quatre images JPEG proviennent de la **démo web publiée** sur https://commerce-360-explorer.vercel.app/ le **19 octobre 2026**, avec une fenêtre navigateur de **1440 × 810 px** et le panneau « À propos » fermé :

Les captures montrent exclusivement les **agrégats historiques Olist de janvier 2017 à août 2018**. Elles ne représentent **ni des données actuelles d'Olist, ni le rapport Power BI local, ni une validation officielle par Olist**. Les prix des articles sont en BRL, hors frais de livraison ; la relation retards/avis est descriptive, non causale.

Les cartes brésiliennes visibles utilisent une adaptation de [@svg-maps/brazil](https://github.com/svg-maps/svg-maps), sous licence **CC BY 4.0** ; voir les crédits intégrés dans le panneau « À propos / Données » de la démo. La Terre est une illustration décorative, sans valeur analytique.

La publication de ces images n'inclut aucun CSV brut, identifiant client, classeur détaillé ou PBIX. Avant toute réutilisation, conserver le contexte, les définitions des KPI et les mentions de sources/licence.
